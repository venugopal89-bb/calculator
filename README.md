# Calculator Layout

## Description

This project is a basic calculator layout created using only HTML. It displays calculator buttons and a display screen but does not perform calculations because no JavaScript is used.

## Features

- Built entirely with HTML
- Calculator-style button layout
- Display screen at the top
- Number buttons (0–9)
- Basic operator buttons (+, −, ×, ÷)
- Clear button (C)

## Technologies Used

- HTML

## Project Structure

## How to Run

1. Save the HTML code in a file named `calculator.html`.
2. Open the file in any web browser.
3. The calculator layout will be displayed.

## Limitations

- Does not perform calculations.
- Buttons are non-functional.
- No styling (CSS) included.
- No JavaScript functionality.
